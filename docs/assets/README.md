# Portfolio Assets

This folder is where you can place recruiter friendly demo captures for the repository.

Recommended assets:

1. `command-deck-overview.png`
   Capture the main dashboard with at least one processed incident.

2. `incident-detail-route.png`
   Capture the `/incidents/{id}` detail view with policy decisions and remediation notes.

3. `benchmark-comparison.png`
   Capture the benchmark panel after running the sample benchmark pack.

4. `incident-demo.gif`
   Record the flow from sample incident creation to investigation, approval, and remediation replay.

The README is already structured so these files can be linked in later without changing the narrative.
